# File upload security checklist

Source of truth for `sk-upload` check IDs. Covers every place users send files (forms, APIs, presigned uploads,
imports, avatars, attachments) and how those files are validated, stored, processed and served, in any language
and with any storage (local disk, S3/GCS/Azure, CDNs). Based on the OWASP File Upload Cheat Sheet (plus the XXE
Prevention and Unrestricted File Upload guidance). `references/guide.md` explains each check.

Columns: **Mode** S = static, D = dynamic. OWASP = OWASP Top 10 2021 / API 2023.

| ID | Check | Mode | Severity | OWASP | CWE |
|---|---|---|---|---|---|
| UPL-TYPE-001 | Allowed types are an allow-list of extensions (checked after decoding/normalizing the name) and file content is verified (magic bytes), not just the client `Content-Type` | S+D | High | A04 | CWE-434 |
| UPL-NAME-001 | Stored names are generated by the server (e.g. UUID); the user's filename never becomes a path (traversal, overwrite, special characters) | S+D | High | A01 | CWE-22 |
| UPL-SIZE-001 | Size limits exist per file, per request and per user; decompression bombs (archives, images) are bounded | S+D | Medium | API4 | CWE-400 |
| UPL-STORE-001 | Uploads are stored outside the web root / application code, never executable, ideally on separate storage or a separate domain | S | Critical | A04 | CWE-434 |
| UPL-SERVE-001 | Files are served with a safe `Content-Type`, `X-Content-Type-Options: nosniff` and `Content-Disposition: attachment` (or from a sandbox domain); HTML/SVG are not rendered inline on the app origin | S+D | High | A03 | CWE-79 |
| UPL-ACL-001 | Storage is private by default; downloads check that the caller may access the file; signed URLs are short-lived | S+D | High | A01 | CWE-284 |
| UPL-PRESIGN-001 | Presigned/direct uploads restrict the key/path, content type, size range and expiry | S | Medium | A01 | CWE-284 |
| UPL-PROC-001 | File processing (images, PDFs, office docs, video) uses patched libraries with hardened settings (ImageMagick policy, Pillow pixel limits, Ghostscript, LibreOffice, ffmpeg) and runs isolated | S | High | A06 | CWE-20 |
| UPL-ARCHIVE-001 | Archive extraction prevents zip slip (entries escaping the target), symlinks and bombs | S | High | A01 | CWE-22 |
| UPL-XML-001 | XML-based uploads (SVG, DOCX, XLSX, XML imports) are parsed with external entities disabled | S | High | A05 | CWE-611 |
| UPL-MALWARE-001 | Files shared with other users are scanned for malware or rebuilt (content disarm & reconstruction) | S | Medium | A08 | CWE-509 |
| UPL-AUTH-001 | Upload endpoints require authentication (unless intended), are rate-limited and CSRF-protected | S | Medium | A01 | CWE-306 |
